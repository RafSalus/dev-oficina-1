# Story 1.5: Camada de Repositório para Acesso a Dados

**Status:** Ready for Review  
**Epic:** Epic 1 (Fundação de Produção e MVP 1)  
**Autor:** River (@sm)  
**Executor:** @dev  
**Quality Gate:** @architect  
**Dependência:** Story 1.4  

---

## 1. Story Narrative

**Como** arquiteto de software do sistema,  
**Quero** que nenhum componente de tela acesse diretamente `localStorage.getItem` ou `setItem` para dados de negócio,  
**Para que** a substituição pelo banco de dados Supabase Postgres no Epic 2 ocorra sem reescrever páginas e formulários.

---

## 2. Acceptance Criteria (ACs)

- [x] **AC1:** Todo acesso a dados de domínio de negócio (clientes, veículos, fornecedores, peças, compras, estoque e OS) é isolado sob módulos na pasta `src/repositories/` com padrão `carregar*()`, `salvar*()` e mutadoras.
- [x] **AC2:** Componentes e páginas de UI têm suas chamadas diretas a `localStorage` migradas para o consumo exclusivo das funções da camada de repositório.
- [x] **AC3:** Preferências estritas de interface do usuário (ex: `header_pinned`, `modal_impressao_dims`, `last_portal_home`) são documentadas e mantidas como exceções legítimas de UI.
- [x] **AC4:** Todas as assinaturas das funções de repositório retornam Promises assíncronas (ou valores resolvidos compatíveis com `async/await`), preparando a troca transparente por chamadas de rede no Epic 2.
- [x] **AC5:** A compatibilidade dos dados existentes em `localStorage` é preservada (CR2), garantindo que dados operacionais já salvos nos navegadores continuem sendo lidos e semeadas as seeds iniciais.
- [x] **AC6:** Cobertura de testes unitários para os repositórios atinge ≥ 60% das linhas de código (NFR6). (Verificado em `tests/unit/repositories.test.js`).

---

## 3. Integration Verification (IVs)

- **IV1:** Todos os 10 domínios continuam carregando e realizando auto-seeding quando o navegador está limpo.
- **IV2:** Criar um cliente, cadastrar uma peça e lançar uma compra atualizam o storage e refletem instantaneamente nas listagens.
- **IV3:** Limpeza completa do cache do navegador re-semeia o sistema perfeitamente.
