# Story 1.3: Tooling de Qualidade Executável (ESLint + Vitest + CI)

**Status:** Ready for Review  
**Epic:** Epic 1 (Fundação de Produção e MVP 1)  
**Autor:** River (@sm)  
**Executor:** @dev  
**Quality Gate:** @qa  

---

## 1. Story Narrative

**Como** desenvolvedor e revisor de código do sistema,  
**Quero** que os scripts `npm run lint` e `npm test` estejam instalados e funcionando,  
**Para que** bugs, regressões nas regras de negócio e violações do `SYSTEM_RULES.md` sejam detectados automaticamente no pipeline antes do deploy.

---

## 2. Acceptance Criteria (ACs)

- [x] **AC1:** ESLint instalado e configurado para React 19 + JSX + Vite (flat config `eslint.config.js`), adotando regras de código limpo e conformidade com `SYSTEM_RULES.md`.
- [x] **AC2:** Vitest instalado e integrado ao ambiente Vite existente via `vitest.config.js`, com `@testing-library/react` e `jsdom` para testes de componentes e hooks.
- [x] **AC3:** `package.json` expõe scripts funcionais: `npm run lint` e `npm test` (além de `npm run test:watch`). O comando inexistente `npm run typecheck` foi removido das referências do `AGENTS.md`.
- [x] **AC4:** Configuração do ESLint opera de forma não-bloqueante no código legado (baseline aceito com warnings) e estritamente bloqueante para arquivos modificados ou novos desenvolvidos no Epic 1 (NFR7).
- [x] **AC5:** Criado workflow no GitHub Actions (`.github/workflows/ci.yml`) que roda `lint`, `test` e `build` em push e pull request nas branches `main` e `develop`.
- [x] **AC6:** A suíte de testes locais executa em menos de 60 segundos (NFR5) — atualmente executando em ~700ms.

---

## 3. Integration Verification (IVs)

- [x] **IV1:** Execução de `npm run lint` roda com sucesso (0 erros) e valida os arquivos novos e legados.
- [x] **IV2:** Execução de `npm test` executa via Vitest e passa 15/15 testes automatizados.
- [x] **IV3:** O build de produção (`npm run build`) mantém seu tamanho sem inflação por bibliotecas de teste (alocadas exclusivamente como `devDependencies`).
